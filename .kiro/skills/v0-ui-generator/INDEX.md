## 🚀 Usage Workflow

### Step 1: Understand Requirements
```
What component do I need?
What data will it display?
What interactions are needed?
```

### Step 2: Find Template
```
Check TEMPLATES.md for similar component
Review QUICK_REFERENCE.md for patterns
```

### Step 3: Generate Component
```
Use template as starting point
Apply design tokens
Follow component rules
Add TypeScript types
```

```
Add to BlockRenderer (if block)
Add TypeScript types
Test with real data
```

### Step 5: Quality Check
```
Run checklist from QUICK_REFERENCE.md
Test responsive design
Verify accessibility
Check dark mode
```

### Design Philosophy

This skill follows these principles:

1. **Consistency** - Follow established patterns
2. **Quality** - Production-ready code
3. **Accessibility** - Built-in from the start
4. **Performance** - Optimized by default
5. **Maintainability** - Easy to understand and modify
6. **Scalability** - Grows with your project

- Always use TypeScript
- Follow mobile-first design
- Prioritize accessibility

- Handle edge cases
- Test thoroughly
- Document clearly

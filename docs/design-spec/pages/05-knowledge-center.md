# Page Spec — Knowledge Center / News

**Figma node:** `26:74`  
**Visible source:** 549 × 1000 raster screenshot.

## Page goal
Support SEO/education, provide category-based discovery and move users from educational content toward booking.

## Section inventory
**6 content groups** plus header/footer.

| # | Section | Layout |
|---|---|---|
| 0 | Header | global nav, Knowledge active |
| 1 | Breadcrumb + title + search | split heading/search |
| 2 | Category filter rail | 7 category tabs |
| 3 | Featured Articles | 3-card grid |
| 4 | Latest Articles + sidebar | 2-column content/sidebar |
| 5 | Pagination | compact numeric controls |
| 6 | Newsletter | dark navy subscribe bar |
| 7 | Footer | global |

## 1. Breadcrumb / Hero Intro
### Desktop
- Breadcrumb left above H1.
- H1 “Knowledge Center”.
- Short supporting copy under title.
- Search box aligned to the right on the same visual band.

### Mobile
- Breadcrumb → title/copy → search full width.
- Search input at least 44–48 px tall.

## 2. Category Filter
Visible categories include:
- All Articles
- Implant Dentistry
- Cosmetic Dentistry
- Orthodontics
- Preventive Care
- Dental Technology
- General Knowledge

### Desktop
- Single horizontal rounded container with evenly spaced icon+label tabs.
- Active category uses blue accent/underline.

### Mobile
- Horizontal scroll with snap; do not shrink 7 labels into one row.

## 3. Featured Articles
### Desktop
- 3 equal cards.
- Large top image approximately 16:10.
- Category badge overlays/aligns near image bottom-left.
- Title, excerpt, date and read time under image.

### Mobile
- 1 column; optional horizontal carousel only if article order is preserved and controls are accessible.

## 4. Latest Articles + Sidebar
### Desktop
- Main column ~68–72%.
- Sidebar ~28–32%.
- Article list rows have thumbnail left, taxonomy/title/summary/meta center, circular arrow action right.
- Sidebar contains:
  - Popular Topics with counts;
  - “Have a Question?” consultation CTA with doctor image.

### Mobile
- Latest Articles first.
- Sidebar modules move below the list.
- Article rows may become 96–120 px thumbnail + content; under 420 px stack thumbnail above title.

## 5. Pagination
- Numeric buttons + previous/next.
- Current page filled blue.
- Touch target ≥44 px even if visual circle is smaller.

## 6. Newsletter
### Desktop
- Deep navy rounded bar.
- Left: mail icon + title/support text.
- Right: email input + bright blue Subscribe button.

### Mobile
- Stack copy above input/button.
- Input and button full width.

## Motion
- Search icon button microinteraction only.
- Category active indicator slides 160–200 ms.
- Article cards fade/translate no more than 12–16 px.
- Avoid auto-scrolling carousels.

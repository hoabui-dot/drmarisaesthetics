# Design System — Accessibility Rules

This document contains the cross-page accessibility baseline formerly stored at `pages/01-home.md`.

- Body text should meet at least 4.5:1 contrast; large text at least 3:1.
- Keep visible focus indicators on all interactive controls.
- Navigation, mobile menus, dialogs, accordions, carousels, forms, and sliders must be keyboard operable.
- Forms need persistent labels, associated errors, and a live-region success message.
